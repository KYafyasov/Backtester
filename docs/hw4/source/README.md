# Assignment source material

This directory preserves the normalized Homework 4 inputs used to define and
verify the implemented system.

- [`01_homework_4_assignment.md`](01_homework_4_assignment.md) is a faithful
  transcription of the written assignment.
- [`02_original_big_picture_mermaid.md`](02_original_big_picture_mermaid.md) is
  a semantic Mermaid transcription of the original architecture diagram.

These files are requirement sources, not descriptions of the final runtime.
For the implemented design, start with
[`../architecture/README.md`](../architecture/README.md). For a direct mapping
from every assignment requirement and diagram box to code and tests, see
[`../architecture/11_requirements_traceability.md`](../architecture/11_requirements_traceability.md).
